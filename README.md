# 岿枢题典

面向 Windows 10/11 x64 的本地题库、考试与刷题工具。程序不需要联网，不上传题库、答案或成绩。

## 已实现功能

- 直接导入机修钳工旧版 Word `.doc`，也支持固定模板的 `.docx`、`.xlsx` 和 `.pptx`。
- 支持填空、判断、选择、简答、计算五大类题型（模板仍兼容多选题）。
- 随机抽题组成总分精确为 100 分的试卷；客观题自动评分，简答和计算题先给建议分再由用户确认。
- 交卷后逐题回看用户答案、正确答案、得分和解析。
- 按导入顺序从头到尾刷题；答对后约 350 毫秒自动进入下一题，答错时停留并显示我的答案、正确答案和解析。
- 支持单独导入机修钳工初级、中级、高级 Word 解析资料；解析可先于题库导入，并按学科、级别、题型、题干指纹和参考答案精确匹配。
- 保存考试记录与错题，支持标记已掌握。
- 本地 SQLite 存储、自动备份、手动备份与恢复。
- 显示题目中的图片和公式，并把附件保存在历史快照中。
- 在设置页一键导出包含五类题型示例的 Excel、Word、PPT 模板。
- 在设置页分别清空本地错题本、练习记录，或仅重置学习概览；每次操作前自动创建安全备份。
- 全新学习首页、左侧导航、专项筛选、错题强化、题号导航和大尺寸答案解析区。
- 无需登录或注册；所有功能继续保持完全离线。

## 解析资料

解析资料不随安装包提供，也不会写入或覆盖题库原有解析。请在“题库管理”页面打开“解析资料”，单独选择 `.docx` 文件导入。

- 每个文件独立校验、独立写入；一个文件失败不会影响同批次的其他文件。
- 相同内容使用规范化 SHA-256 识别，即使文件改名也会提示替换或取消。
- 列表显示总条目、已匹配、待匹配和答案冲突；不使用模糊匹配。
- 多个资料包都能精确匹配时使用最近导入的版本；删除后自动回退到较早资料包或题目自带解析。
- 删除资料包只删除解析，不删除题目、错题、答案、成绩或历史记录。

100 分试卷交卷后以及练习记录中的历史试卷，均使用同一个逐题回看页面。答案和解析在交卷前保持隐藏；交卷后可通过右侧题号或“上一题”“下一题”查看题干、选项、作答结果、得分、解析和附件。

## 本地开发

需要 Python 3.12：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m offline_quiz.app
```

运行测试：

```powershell
$env:QT_QPA_PLATFORM="offscreen"
.\.venv\Scripts\python.exe -m pytest
```

## Windows 打包

安装 Inno Setup 6，并按 [`third_party/README.md`](third_party/README.md) 准备好本地 LibreOffice Portable 后运行：

```powershell
.\packaging\build.ps1
```

脚本先运行测试，再生成 `dist\KuishuQuiz` 应用目录，并在 Inno Setup 可用时生成 `dist\installer\KuishuQuiz-Setup-1.6.0-test9.exe`。

> GitHub 仓库只保存可维护的源码、测试、打包脚本和界面素材。解析 Word、提取后的解析数据、虚拟环境、构建产物、用户题库数据库以及体积过大的 LibreOffice 二进制文件均不会提交。

## 格式边界

程序不使用 AI，也不从普通文章、扫描件或任意排版课件中自动生成题目。旧版 `.doc` 仅识别机修钳工题库的五章节结构；其他 Word、Excel 和 PPT 应使用设置页导出的固定模板。原文缺少答案或只有图片公式时会明确标记为待人工补充，不会伪造答案或直接判零分。
