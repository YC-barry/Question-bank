# 岿枢题典 test4 接力设计

## 目的

把 `KuishuQuiz-handoff-2026-11-12.zip` 中已经在另一台电脑验证的修复正式合并回源码，并生成新的、可独立安装的 `test4` 版本。目标用户继续使用完全离线、无需登录的 Windows 10/11 x64 桌面题库软件。

## 已确认问题

- Windows 应用深色模式会给普通 Qt 控件继承浅色前景色，而现有样式把输入框、下拉框和表格背景固定为白色，造成白字白底。
- 现有源码仍使用“离线题库助手”品牌；交接版本已改为“岿枢题典”。
- 交接数据库完整，包含 1 个题库、771 道题、15 个图片资源、2 次会话、20 条答题记录和 19 条错题。

## 选定方案

采用源码级正式合并，不继续使用交接包中的 PyInstaller 二进制补丁器。全局 QSS 明确设置普通控件、输入控件、下拉弹出列表和表格的深色文字；所有用户可见品牌统一改为“岿枢题典”。实际可执行文件使用 `KuishuQuiz.exe`，由安装器创建中文快捷方式。

保留以下兼容标识：

- 数据目录仍为 `%LOCALAPPDATA%\OfflineQuiz\data`，避免旧题库和记录失联。
- Inno Setup `AppId` 保持不变，支持覆盖升级。
- 卸载时仍按用户确认删除 `%LOCALAPPDATA%\OfflineQuiz`。

## 考虑过的方案

1. **源码级合并（选定）**：可维护、可测试、后续打包自动带上修复；需要重新构建安装包。
2. **继续修补 PyInstaller EXE**：能快速救急，但依赖归档内部布局，版本升级容易失效，不作为正式发布方式。
3. **完全改为中文 EXE 文件名**：用户观感直接，但交接电脑已出现 `0xc0000409`，因此 test4 保留英文 EXE 和中文快捷方式。

## 数据处理

交接数据库只用于完整性验证和用户自己的数据恢复，不写入安装包，也不自动覆盖当前电脑数据库。这样给其他人发送安装包时不会泄露题库、练习记录或错题数据。

## 发布约定

- 用户可见版本：`1.3.0-test4`
- Python 包版本：`1.3.0.dev4`
- 安装包：`KuishuQuiz-Setup-1.3.0-test4.exe`
- 发布目录：`D:\工具\刷题软件\test4`
- `test1`、`test2`、`test3` 保持不变。

## 验收

- 深色/浅色系统主题下，浅色界面的输入框、下拉列表和表格文字均保持深色可见。
- 窗口标题、侧边栏、应用名称、模板、安装器和文档显示“岿枢题典”。
- `KuishuQuiz.exe` 能从安装目录运行，中文快捷方式正确指向它。
- 旧 `%LOCALAPPDATA%\OfflineQuiz` 数据继续可用。
- Word/PPT/Excel 导入、顺序刷题、随机组卷、100 分试卷、评分、答案显示、错题和历史回归通过。
- 生成 test4 安装包并验证校验码、打包应用启动及真实 `.doc` 导入。
