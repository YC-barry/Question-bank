# test6 学习首页与顺序刷题回看设计

## 目标

让顺序刷题支持回看已经作答的题目并恢复当时选择，同时将题型筛选改为直观的多选方式；学习首页升级为以真实答题记录计算的学习概览。

## 交互设计

- 顺序刷题提交后，题号导航继续开放全部已作答题以及下一道未答题。点击旧题时恢复用户当时的答案，锁定输入，并持续显示对错、正确答案和解析。
- 判断题仍保持点击“对/错”立即批改；恢复历史选择只更新界面，不得再次提交。
- 顺序刷题和试卷设置页使用六个可勾选题型按钮。默认全选；用户可只选一种，也可组合选择；至少保留一种题型。
- 首页采用浅蓝白色卡片式布局，保留左侧导航，增加顶部快捷入口、四项统计、总体进度、近七日练习趋势、各题型完成度、最近活动和常用功能。

## 统计口径

- 总体进度：当前仍存在的题目中，曾经提交过答案的不同题目数 / 当前题目总数。
- 正确与错误：每道当前题目采用最近一次作答结果；之后答对的题目归入正确，之后答错的归入错误。
- 练习趋势：最近七个自然日每天提交的答案数量，包含顺序刷题和试卷。
- 题型完成度：该题型已作答过的不同题目数 / 当前该题型总数。
- 最近活动：最近四次有作答记录的会话；未完成的顺序刷题也可显示已练题量。

## 技术方案

- 在 `Database` 增加只读聚合查询 `learning_overview()`，避免首页加载题目正文和附件。
- 新增轻量 PySide6 自绘进度环与趋势折线，不增加网络或图表库依赖。
- 首页在滚动容器中布局，以兼容 1366×768 的可用桌面高度。
- 数据库结构不变，继续兼容现有 `%LOCALAPPDATA%\OfflineQuiz\data` 数据。

## 其他方案

- 单选下拉框改动最小，但不能组合选择且不够直观，不采用。
- 引入 QtCharts 或 matplotlib 可以快速绘图，但会增加安装包体积和部署复杂度，不采用。
- 按总作答次数计算进度会被重复刷题无限抬高，不能反映题库覆盖率，不采用。
