# 岿枢题典用户手册

## 学习首页与导航

软件无需登录，打开后直接进入学习首页。左侧可进入题库管理、100 分试卷、顺序刷题、错题强化、练习记录和设置。首页显示本地题库数、题目总数、待强化错题数和已完成练习数，并提供顺序刷题、生成试卷和导入题库快捷入口。

“学习概览”包含总体进度、近 7 天练习趋势和各类题完成情况。总体进度和分类进度按“已经作答过的不同题目数”计算，重复练习同一道题不会重复增加；最近答对、最近答错采用每道题最后一次作答结果。页面下方还可查看最近活动和常用功能，窗口高度不足时使用右侧滚动条查看。

## 导入题库

1. 打开“题库”，点击“导入 Word / PPT / Excel”。
2. 可以直接选择机修钳工五章节结构的旧版 `.doc`，也可以选择固定模板 `.docx`、`.xlsx`、`.pptx`。
3. 程序显示填空、判断、选择、简答、计算题量，以及图片/公式附件数和警告数。
4. 确认后选择重复题采用覆盖或跳过。原文答案不完整的题会保留并标为待人工补充。

若要建立新题库，请在“设置”中导出三种题库模板。Excel 每个工作表代表一个题库；固定模板 Word 每题用 `---` 分隔；PPT 每页一道题。三种模板均含五类示例。

旧版 `.doc` 的转换完全离线，由随软件安装的 LibreOffice 组件完成，不要求电脑安装 Office、WPS 或 LibreOffice，原文件不会被修改。

## 100 分试卷

1. 打开“100分试卷”。
2. 选择题库、分类、难度、题型和抽题数量。题型按钮支持单独选择或多种组合，至少需要保留一种。
3. 程序无放回随机抽题，并按原题分值权重把整卷归一化为 100 分。
4. 答题过程中可以前后切换。提交后客观题立即判分；若包含简答或计算题，会先打开人工复核窗口。
5. 人工复核窗口同时显示作答、标准答案、解题过程、自动建议和建议分。逐题确认最终得分后才保存整卷成绩。
6. 完成后显示总分和正确率，并可回看每一道题。

## 顺序刷题

选择题库后开始刷题。可按分类、难度、标签筛选，并通过六个题型按钮单独选择或组合选择要练习的类型。程序按导入顺序展示题目，右侧题号导航显示当前题和已完成题。判断题点击“对”或“错”后立即批改；其他客观题点击“提交本题”后批改。批改后答案被锁定，并在大尺寸答案区显示我的答案、正确答案、得分和解析；简答和计算题提交后先显示建议，再由用户确认本题最终得分。图片和公式会随题显示。

完成后面的题目时，可以点击右侧已经做过的题号返回查看。软件会恢复当时选择或填写的答案，同时继续显示判定结果、正确答案和解析；回看不会重复提交或增加错题次数。

## 错题与记录

答错的题目自动进入错题本。点击“开始错题强化”可仅练习尚未掌握的错题。答对不会自动移除错题，需要手动标记“已掌握”。“练习记录”可查看历次答题详情，即使原题后来被修改或删除，历史快照仍保留。

## 本地数据

数据默认保存在 `%LOCALAPPDATA%\OfflineQuiz\data`。应用启动及数据库升级前自动备份，最多保留最近 5 份；升级失败会恢复原库。设置页可以手动备份或恢复。整个流程无需联网，题库、答案和成绩不会上传。

## 人工调整说明

- 原文缺少标准答案、选项不完整、公式仅存在于图片或答案写“略”时，软件会保留题目并要求人工确认。
- 自动建议只用于辅助判断，不会绕过人工复核成为最终成绩。
- 可在题库管理中编辑题干、标准答案、参考过程和分值；历史答题快照不会随原题修改而变化。
